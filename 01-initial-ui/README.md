# Configure Default Terminal

- In Visual Studio Code select menu View->Command Palette...

- At the > prompt enter
  Terminal: Select Default Profile

- Regardless of whether you are on windows or mac, choose the Bash terminal : we are going to be using that throughout the course

# Open A Terminal Window

- In Visual Studio Code right click on the 01-initial-ui folder in the explorer, and select "Open In Integrated Terminal"

- You should then see a bash terminal window at the bottom of the screen

# Run Vite

enter the commands

```
npm install
npm run dev
```

# Open the Link And View The Website

- Hold the command (mac) or control (windows) key down and click on the link in the terminal (most likely http://localhost:5173/)
